Traffic & Road Safety Data Analysis

Overview

This project analyzes road accident data from 2005 to 2017 using Python. The main goal is to understand accident patterns, weather conditions, road surface conditions, vehicles involved, and casualties.

Dataset

- Rows: 2,047,256
- Columns: 34
- Period: 2005–2017

Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis

- Data Inspection
- Missing Values & Duplicates
- Sorting & Grouping
- Correlation Analysis
- Statistical Analysis
- Data Visualization

Key Findings

- No duplicate rows were found.
- Most accidents occurred in fine weather.
- Dry roads had the highest number of accidents.
- Most accidents involved two vehicles.
- The average number of casualties was 1.35 per accident.
- The maximum number of casualties in a single accident was 93.

Conclusion

This analysis provides useful insights into road accident patterns, weather conditions, road surfaces, vehicle involvement, and casualty distribution.
